# 開発進捗提出フォーム

二人でゲームを開発する際に、個人で進めたプログラムと作業内容を共有するための提出フォームです。

提出データはGoogleドライブに保存されるため、相手のPCがオフでも開発状況を確認できます。

## 主な機能

- 提出者名・作業日・作業内容の記録
- 次にやること・相談事項の記録
- プログラムやZIPファイルの提出
- 提出履歴の表示
- 名前・作業内容による検索
- 作業日による絞り込み
- 提出ファイルへのリンク
- 毎日21:00（日本時間）の提出目安を表示
- 提出後に指定したメールアドレスへ通知

21時を過ぎても提出できます。
作業がない日は、ファイルを付けずにメモだけ提出できます。

## 使用技術

- HTML
- CSS
- JavaScript
- Google Apps Script
- Googleドライブ
- MailAppによるメール送信

## ファイル構成

```text
project/
├── index.html
├── style.css
└── main.js
```

Google Apps Script側には、保存・通知処理を行う`コード.gs`を配置します。

| ファイル | 役割 |
| --- | --- |
| index.html | 提出フォームと履歴画面 |
| style.css | デザイン・スマートフォン対応 |
| main.js | 入力処理・通信・履歴表示 |
| コード.gs | ファイル保存・履歴取得・メール通知 |

## システムの仕組み

1. フォームに名前と作業内容を入力します。
2. 必要に応じてファイルを添付します。
3. JavaScriptからGoogle Apps Scriptへ送信します。
4. Googleドライブに提出ごとのフォルダを作成します。
5. 添付ファイルと提出情報を保存します。
6. 指定したメールアドレスへ通知します。
7. フォームの提出履歴を更新します。

提出情報は、各提出フォルダの`_submission.json`に保存します。

## 初期設定

### 1. Googleドライブに保存先を作成

Googleドライブで提出用フォルダを作成します。

フォルダを開いたときのURLから、`folders/`より後ろの文字列をコピーします。

```text
https://drive.google.com/drive/folders/フォルダID
```

### 2. Google Apps Scriptを設定

Google Apps Scriptで新しいプロジェクトを作成し、保存処理のコードを`コード.gs`に貼り付けます。

先頭の設定値を変更します。

```javascript
const FOLDER_ID = "保存先フォルダのID";

const VIEWER_EMAIL = "";

const TEAM_KEY = "フォーム専用の長いランダムな合言葉";

const NOTIFY_EMAIL = "通知を受け取る自分のメールアドレス";
```

| 設定項目 | 内容 |
| --- | --- |
| FOLDER_ID | 提出データを保存するフォルダのID |
| VIEWER_EMAIL | 保存済みファイルを見せたい相手のGoogleアカウント |
| TEAM_KEY | フォームとApps Scriptで共通の合言葉 |
| NOTIFY_EMAIL | 提出通知を受け取るメールアドレス |

相手へのフォルダ共有を後で設定する場合は、`VIEWER_EMAIL`を空欄にします。

### 3. フォルダを共有する場合

相手にも提出ファイルを見せたい場合は、`VIEWER_EMAIL`を設定して、Apps Scriptの`setup`を実行します。

相手は閲覧者として追加されます。共有通知が届く場合があります。

`VIEWER_EMAIL`が空欄の場合は、`setup`を実行しません。

フォルダ共有は添付ファイルの閲覧権限を設定する処理です。
フォームから提出するための合言葉とは別の仕組みです。

### 4. メール通知をテスト

1. Apps Scriptを保存します。
2. 関数選択で`testNotification`を選びます。
3. 「実行」を押します。
4. 必要な権限を許可します。
5. 通知先にテストメールが届くか確認します。

`NOTIFY_EMAIL`はApps Script側に設定します。
`main.js`には追加しません。

### 5. ウェブアプリとしてデプロイ

「デプロイ」→「新しいデプロイ」を選び、種類を「ウェブアプリ」にします。

| 項目 | 設定 |
| --- | --- |
| 次のユーザーとして実行 | 自分 |
| アクセスできるユーザー | 全員 |

デプロイ後、末尾が`/exec`のウェブアプリURLをコピーします。

デプロイID単体ではなく、ウェブアプリURLを使用してください。

Googleアカウントや組織の制限により、「全員」を選べない場合があります。

### 6. main.jsを設定

`main.js`の先頭を設定します。

```javascript
const API_URL = "取得したウェブアプリのURL";

const TEAM_KEY = "Apps Scriptと同じ合言葉";
```

合言葉は、大文字・小文字も含めて完全に一致させてください。

## 起動方法

1. `index.html`・`style.css`・`main.js`を同じフォルダに置きます。
2. VS Codeで「ファイル」→「フォルダーを開く」を選びます。
3. 3ファイルの入ったフォルダを開きます。
4. Live Server拡張機能をインストールします。
5. `index.html`を開きます。
6. 右下の「Go Live」を押します。

## 提出方法

1. 提出者名を入力します。
2. 作業日を選びます。
3. 今日の作業内容を入力します。
4. 必要に応じて次の作業・相談事項を入力します。
5. 提出するファイルを選びます。
6. 「作業内容を提出する」を押します。
7. 完了表示を確認します。

提出中は画面を閉じないでください。

フォルダ全体を提出する場合は、ZIPファイルにまとめてください。

## ファイル制限

- 最大10ファイル
- 合計10MB（10 × 1024 × 1024バイト）

対応する拡張子：

```text
.html .css .js .json .txt .md .zip
.c .cpp .h .cs .py .java .ts .tsx .jsx
```

Googleドライブの空き容量やApps Scriptの実行上限にも影響されます。

## 提出履歴

ページを開いたとき、または「更新」を押したときに履歴を取得します。

以下の操作ができます。

- 名前・作業内容で検索
- 作業日で絞り込み
- 提出ファイルのリンクを開く

ファイルのリンクはGoogleドライブを開きます。
閲覧には、そのファイルへのアクセス権が必要です。

提出者名はブラウザーに保存されます。
提出内容と添付ファイルはGoogleドライブに保存されます。

## メール通知

新しい提出を保存すると、以下の情報をメールで通知します。

- 提出者名
- 作業日
- 今日の作業内容
- 次にやること・相談事項
- 提出ファイルへのリンク
- 保存先フォルダへのリンク

ファイル本体はメールに添付しません。

自分のテスト提出も通知対象です。
通知に失敗しても、提出データは保存されます。

画面の「提出しました」は、通知メールの到着を保証するものではありません。

## 変更を反映する方法

### HTML・CSS・JavaScriptを変更した場合

ファイルを保存し、ブラウザーを再読み込みします。

### Apps Scriptを変更した場合

コードを保存した後、デプロイを更新します。

1. 「デプロイ」→「デプロイを管理」を開きます。
2. 使用中のデプロイを選びます。
3. 鉛筆マークを押します。
4. バージョンを「新バージョン」にします。
5. デプロイします。

既存デプロイを更新した場合、URLは変更不要です。

新しいデプロイを作った場合は、`main.js`の`API_URL`を新しいURLに変更してください。

## 公開時の注意

現在の構成は、二人だけでファイルを使う簡易構成です。

`main.js`に合言葉が含まれるため、そのままGitHubの公開リポジトリや公開サイトに掲載しないでください。

- JavaScript内の合言葉は閲覧者が確認できます。
- 合言葉を知る人は提出や履歴取得ができます。
- 提出者名は自己申告で、本人確認は行いません。
- Googleアカウントのパスワードを合言葉に使わないでください。

合言葉を誤って公開した場合は、Apps ScriptとJavaScriptの両方で変更し、デプロイを更新してください。
古い合言葉を使うデプロイが残っている場合は、そちらも無効化してください。

公開URLで運用する際は、合言葉をソースに埋め込まず利用時に入力する方式、または適切なログイン方式へ変更してください。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| デザインが表示されない | CSSの名前が`style.css`か、同じフォルダにあるか |
| ボタンや履歴が動かない | JSの名前が`main.js`か、読み込めているか |
| Open a folder or workspaceと表示される | VS Codeでフォルダを開いているか |
| 合言葉が一致しない | Apps ScriptとJSの合言葉、デプロイのバージョン |
| 通信に失敗する | `/exec`のURL、公開範囲、権限、ネットワーク |
| 保存に失敗する | フォルダID、アクセス権、ファイル形式・容量 |
| メールが届かない | 通知先、迷惑メール、送信権限、実行ログ |
| 相手がファイルを開けない | Googleアカウントとフォルダ共有の設定 |
| 変更が反映されない | 再読み込み、デプロイ更新、URL変更 |

通信エラーが出ても、保存が完了している場合があります。
再提出する前に履歴を更新し、提出済みか確認してください。
